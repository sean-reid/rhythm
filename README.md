# rhythm

Generative drum rhythms from hierarchical Markov transition matrices. Live at [rhythm.dwainosaur.com](https://rhythm.dwainosaur.com).

Short rhythm atoms are generated by per-voice Markov chains over hit strengths. A layer above walks a transition matrix that picks which atom comes next. Each further layer picks which matrix the layer below is walking, so higher layers modulate the rhythm over longer stretches of time. Every piece is reproducible from the seed and matrices in its URL.

## Install

```sh
npm install
```

## Usage

```sh
npm run dev        # local dev server
npm test           # engine unit tests
npm run e2e        # Playwright, needs `npx playwright install chromium` once
npm run build      # production build into dist/
npm run deploy     # deploy the Worker and assets with wrangler
```

Keys while playing: space plays and pauses, R rerolls the seed, L adds a level, T taps tempo, ? lists the rest.
